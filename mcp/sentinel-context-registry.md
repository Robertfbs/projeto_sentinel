# Context Registry do Sentinel

## `sentinel_project_context`

- PRD
- TechSpec
- README
- regras de negócio aprovadas
- componentes canônicos

## `sentinel_operational_context`

- fontes obrigatórias
- status de execução
- outputs esperados
- critérios de validação

## `sentinel_analytics_context`

- métricas oficiais
- fatos e dimensões
- filtros executivos
- definição de ticket válido

## `sentinel_audit_context`

- regras de auditoria
- exceções conhecidas
- overrides persistidos
- reconciliação Gold x outputs

## `sentinel_ai_ready_context`

- campos textuais normalizados
- exclusões executivas
- camadas limpas para embeddings e busca semântica
