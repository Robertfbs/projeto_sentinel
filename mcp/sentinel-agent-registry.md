# Agent Registry do Sentinel MCP

## `sentinel-etl-agent`

Responsável por:
- contratos de dados
- execução governada do ETL
- observabilidade e reconciliação

## `sentinel-bi-agent`

Responsável por:
- camada semântica
- métricas oficiais
- consumo em Power BI

## `sentinel-audit-agent`

Responsável por:
- inconsistências
- divergências
- validação de correções persistidas

## `sentinel-ai-readiness-agent`

Responsável por:
- padronização textual
- AI-ready layer
- apoio a busca semântica e automação futura
